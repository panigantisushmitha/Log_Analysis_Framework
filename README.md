# Configurable Log Analysis and Report Generation Framework 

## Overview

This project analyzes application log files, extracts structured information, generates summary statistics, and creates a report.

## Features

- Parse multiple log files
- Count INFO, WARNING, and ERROR logs
- Count repeated messages
- Generate a text report
- Configurable through JSON

## Technologies Used

- Python
- Regular Expressions
- JSON
- Object-Oriented Programming
- File Handling

## Project Structure

- parser.py
- analyzer.py
- report_generator.py
- utils.py
- main.py

## Run

python main.py
